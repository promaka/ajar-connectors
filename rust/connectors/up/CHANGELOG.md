# Changelog: up

Changes to this one package, released on its own as the tag `up-vX.Y.Z`.
The format is based on Keep a Changelog (https://keepachangelog.com). The
version follows semver, and the entity types and attributes it emits count as
its public interface: renaming or removing one is a major bump (see
CONTRIBUTING.md, "Releases").

## [Unreleased]

## [0.6.6] - 2026-10-27

### Changed

- First release on its own, as the tag `up-v0.6.6`: its own tarball and GitHub
  release. Connectors are no longer in the same tarball: download `ajar-up` once
  and the connector your packet names next to it. When that connector is
  missing, the error now says which release to download.

## [0.6.5] - 2026-10-24

The last release of the whole suite at one version. History up to here is in
the [repository changelog](../../../CHANGELOG.md).
