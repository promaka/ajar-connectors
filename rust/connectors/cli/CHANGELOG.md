# Changelog: connectors

Changes to this one package, released on its own as the tag `connectors-vX.Y.Z`.
The format is based on Keep a Changelog (https://keepachangelog.com). The
version follows semver (see CONTRIBUTING.md, "Releases").

## [Unreleased]

### Added

- `ajar-connectors`, the one command for a machine that runs connectors:
  `setup`, `install`, `update`, `list`, `uninstall`, `join`, `request`, `run`,
  `start`, `stop`, `status`, `logs`, `check` and `remove`. It replaces
  `ajar-up` and the `ajar-doctor` binary.
